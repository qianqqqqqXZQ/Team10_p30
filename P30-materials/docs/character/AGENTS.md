## 适用范围与用途

新增、更新或整理成员个人信息文档之前，必须先阅读本文件。

## 统一文档结构

- 使用 UTF-8 编码，说明文字默认使用中文；姓名、技术名称和必要的英文术语保留原文。
- 仅使用一个一级标题，内容为成员的完整英文姓名。
- 必须保留以下五个二级标题及其顺序：基本信息、个人简介、技能与特长、相关项目与经验、本项目职责。
- “基本信息”使用无序列表，按顺序保留姓名、小组角色、专业与年级三个字段。
- 用户提供学号或邮箱后，在上述三个字段之后依次补充“学号”“邮箱”；未提供的联系方式不推测。
- “个人简介”使用段落；技能、经验和职责在有具体内容时使用无序列表，每条描述一个技能、经历或职责。
- 标题与正文、段落与列表之间留一个空行。
- 未提供的基本信息字段填写 `待补充`，未提供的章节正文填写 `待补充。`，不要删除对应字段或章节。

### 文档模板

```markdown
# 完整英文姓名

## 基本信息

- 姓名：完整英文姓名
- 小组角色：成员（具体分工待补充）
- 专业与年级：待补充

## 个人简介

待补充。

## 技能与特长

待补充。

## 相关项目与经验

待补充。

## 本项目职责

待补充。
```

## 内容维护规则

- 只记录用户或成员提供的真实信息，不推测或编造专业、年级、技能、项目经历和职责。
- 区分已有技能与计划学习的技能，描述项目经验时写清个人实际承担的工作。
- 项目职责以已确认的分工为准，尚未明确的职责保留为待补充。
- 更新时保留其他已确认信息；仅修改本次涉及的成员及内容。
- 更新完成后检查文件名、标题和姓名是否一致，五个章节是否齐全且顺序正确，基本信息字段是否完整。
